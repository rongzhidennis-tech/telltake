# Telltake documentation

- `product-brief.md` — product promise, target workflow, safety/quality bar
- `code-architecture.md` — modules, ports/adapters, growth plan
- `decisions/` — architecture decision records (ADR-001 … ADR-110) and the governing index
- `workflows/` — per-stage behavioural specs the implementation was built against
- `schema/` — SQLite catalog (`sqlite-schema.sql`, `sqlite-schema.md`) and ordered migrations
- `evaluation-protocol.md`, `dataset-registry.md`, `evidence/` — how quality is defined and measured
- `experiments/` — speech-provider comparisons and text-cleanup trials (operator tooling, not app features)
- `privacy.md` — exactly what leaves the user's Mac
- `glossary.md` — vocabulary used across the docs
- `media/` — screenshots used by the top-level README
